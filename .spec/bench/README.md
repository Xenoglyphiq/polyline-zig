# Benchmarks

| File | What |
|---|---|
| `route_100k.polyline` | 100,000 points at precision 5, one line (trailing newline is not part of the polyline). Generated by `generate.py` from a seeded random walk; re-running gives identical bytes. |

Each port reports two numbers on this input: **encode** (decode the file once, then time encoding the points) and **decode** (time decoding the string). The reference is the Rust `polyline` crate; its pinned version and timings will be recorded here before the first port reaches M3. Target: within 2× of the reference (`spec/SPEC.md` §8).
